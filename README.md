# 🛍️ Danyzaa Shopzee 💅

A responsive mini shopping website built using **HTML5, CSS, and JavaScript**.

## 📌 About the Project

**Danyzaa Shopzee** is a mini shopping website created as a front-end development project. It includes product browsing, search functionality, cart management, product details, and responsive design for mobile devices.

## ✨ Features

- 🛍️ 15 Products
- 🔍 Product Search & Filter
- 🛒 Add to Cart
- 🔢 Increase / Decrease Quantity
- 🗑️ Remove Products from Cart
- 💰 Automatic Total Price Calculation
- 📄 Product Details Page
- 🔄 Cart & Product Details Navigation
- 💾 LocalStorage for Cart Data
- 📱 Responsive Mobile Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
