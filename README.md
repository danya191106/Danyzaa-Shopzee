# 🛍️ Danyzaa Shopzee 💅

### Mini Shopping Website

Danyzaa Shopzee is a responsive mini shopping website built using **HTML5, CSS3, and JavaScript**. It provides a simple shopping experience with product browsing, search, product details, and cart management.

## 🌐 Live Demo

[View Live Demo] https://danyzaa-shopee.netlify.app


## 📌 About the Project

Danyzaa Shopzee is a front-end project created to practice building an interactive shopping website using JavaScript and DOM manipulation.

The website includes fashion, beauty, and footwear products with a clean and responsive user interface.

## ✨ Features

- 🛍️ 15 Products
- 🔍 Product Search & Filter
- 🛒 Add to Cart
- ➕➖ Increase / Decrease Quantity
- 🗑️ Remove Products from Cart
- 💰 Automatic Total Price Calculation
- 📄 Product Details Page
- 🔄 Product & Cart Navigation
- 💾 LocalStorage for Cart Data
- 📱 Responsive Mobile Design

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, animations, and responsive design
- **JavaScript** – Interactivity and dynamic functionality
- **DOM Manipulation** – Updating and creating page content dynamically
- **LocalStorage** – Storing cart data in the browser
